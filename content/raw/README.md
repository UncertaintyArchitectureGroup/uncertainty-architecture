# Raw Source Archive

This directory preserves source snapshots used to create normalized repository editions under [`content/research/publications/`](../research/publications/).

Files here are retained for provenance, comparison, and recovery. They may contain platform metadata, formatting residue, historical terminology, duplicated sections, broken links, or claims that were later refined.

Raw snapshots are **not normative UA documents** and should not be edited to match later framework decisions. Corrections, normalization, translations, and consolidated editions belong in the Research Track with an explicit provenance record.

The canonical research namespace is [`content/research/`](../research/). Public project history belongs in [`content/history/`](../history/).
