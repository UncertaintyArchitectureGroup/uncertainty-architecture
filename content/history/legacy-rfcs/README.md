# Legacy RFC Process

This directory preserves an RFC scaffold drafted in January 2026 during an earlier governance design for Uncertainty Architecture.

The process was **not adopted as the current repository workflow**. Its mandatory private-repository, co-author-consensus, advisor-review, and staged RFC assumptions were superseded by the maintainer-led contribution model in [`CONTRIBUTING.md`](../../../CONTRIBUTING.md) and the change-control rules in [`SPECIFICATION.md`](../../../SPECIFICATION.md).

These files are retained only as historical decision context:

- [`0000-template.md`](0000-template.md) — the retired proposal template;
- [`0001-governance-process.md`](0001-governance-process.md) — the draft governance proposal.

They MUST NOT be cited as current UA governance or as an active requirement for contributing changes.
